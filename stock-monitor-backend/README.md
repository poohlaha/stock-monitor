# stock-monitor
  `stock-monitor` 桌面壳子以及后端服务调用。
  
- [文档](https://beta.tauri.app/guides/)

## 使用
下载 `Web 端` 和 `后端` 放于同一目录下, 然后运行如下命令

```shell
make webInstall
```

## 运行及构建
```shell
make run # 运行
make build # 打包
```

## 检查动态链接库
```shell
otool -L src-tauri/target/release/stock-monitor
```
